## English

### 1. Project Description
This is the official product landing page for the **Rest Your Eyes** Android application. It is designed with a premium, modern aesthetic utilizing glassmorphism and dynamic gradients to showcase the app's features and provide a direct download link.

### 2. Technologies Used
- **Framework:** Vite
- **Styling:** Vanilla CSS & Tailwind CSS v4
- **Deployment:** Vercel

### 3. Key Learnings
During the construction of this landing page, I learned how to configure and integrate **Tailwind CSS v4** within a **Vite** environment for lightning-fast development. Furthermore, I honed modern design techniques such as **Glassmorphism** (translucent, blurred backgrounds) and the use of gradients to create a premium, fluid, and fully responsive visual experience.

### 4. Local Setup Instructions
To run this web project locally:
1. Ensure you have Node.js installed.
2. Navigate to this directory: `cd web`
3. Install dependencies: `npm install`
4. Run the development server: `npm run dev`

## Español

### 1. Descripción del Proyecto
Esta es la página oficial de producto para la aplicación Android **Rest Your Eyes**. Está diseñada con una estética moderna y premium utilizando *glassmorphism* y gradientes dinámicos para mostrar las características de la app y proveer un enlace de descarga directo.

### 2. Tecnologías Utilizadas
- **Framework:** Vite
- **Estilos:** Vanilla CSS & Tailwind CSS v4
- **Despliegue:** Vercel

### 3. Aprendizajes Clave
Durante la construcción de esta landing page, aprendí a configurar e integrar **Tailwind CSS v4** dentro de un entorno **Vite** para lograr un desarrollo ultrarrápido. Además, perfeccioné técnicas de diseño moderno como el *Glassmorphism* (fondos translúcidos y desenfocados) y el uso de gradientes para crear una experiencia visual premium, fluida y completamente adaptable a cualquier pantalla.

### 4. Instrucciones de Configuración Local
Para correr este proyecto web localmente:
1. Asegúrate de tener Node.js instalado.
2. Navega a este directorio: `cd web`
3. Instala las dependencias: `npm install`
4. Inicia el servidor de desarrollo local: `npm run dev`
